Territory Run 🏃‍♂️🗺️

A full-stack GPS fitness tracking and territory claiming platform built using Next.js, TypeScript, MongoDB, and Mapbox.
Users can track runs, monitor fitness statistics, claim territories on the map, compete on leaderboards, and manage their profiles through a modern responsive web application.
🚀 Features
🔐 Secure Authentication (Google OAuth + Email/Password)
📍 Live GPS Run Tracking
🗺️ Interactive Territory Claiming System
🏆 Global Leaderboards
📊 Fitness Analytics Dashboard
👤 User Profiles & Statistics
🌙 Modern Dark UI
⚡ REST API Architecture
📱 Mobile App Backend Support
🔒 JWT Protected APIs
